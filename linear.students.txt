What is a linear model?

	A \emph{fit} to a \textbf{response variable} based on assumptions about its relationship to one or more \textbf{predictor variables}

	\emph{Inferences} about parameters based on assumptions about the \emph{conditional} distribution of the response variable

		Assume the response variable has “true” distribution for any value of the predictor variables

			STUDENTS Use temperature to predict deaths	

	A linear model gives the response variable as a linear combination of the \emph{parameters} it is estimating

----------------------------------------------------------------------

Linear model?

$y$ is response, $x$ is predictor

	$y = a + b x$

	$y = a + b x + c x^2 + d x^3$

	$y = \frac{a}{b+x}$

	$y = a x^b$

	$\log(y) = \log a + b \log(x)$

Assumptions

	Linear-model \emph{fits} are basically always correct, but can be hard to interpret

		You can find the “best” parameters

		But you need assumptions to know what that means

	Linear-model \emph{inferences} (parameter estimates P-values, CIs) depend on assumptions about \emph{residuals}

	A residual is $y-\hat y$: the difference between an observed value $y$ and a model prediction $\hat y$

	lm inference assumes that residuals are independent and normally distributed, with constant variance

		The mean of the residuals is always 0

The Central Limit Theorem

	Most distributions converge to a normal distribution if you add up independent random variables and take the mean

		Variables that result from additive processes will tend to be normal

		COMMENT Variables that result from multiplicative processes will tend to be lognormal

		Tests based on normality assumptions will be less sensitive to that assumption when there is more data

			There is adding and averaging going on inside the test

Controlling

	Adding a second variable when our primary interest is the first is called “controlling”

	When you control for a variable, you don't necessarily need to interpret the parameters of that variable at all!

----------------------------------------------------------------------

Conflation

	Why do children who smoke have higher lung capacity?

	This is called conflation, or confounding

----------------------------------------------------------------------

Accounting for variation

	Even when we don't have conflation, controlling for relevant predictors can make our predictions more accurate

	Example, randomized controlled trial of a blood-pressure drug

----------------------------------------------------------------------

How many parameters?

	Statistics isn't magic

		The linear model will find patterns even in noise

	Controlling for too many factors will make our predictions less \emph{precise}

	Rule of thumb:

		5--10 solid, continuous data points per parameter

		When data points are small counts, or yes/no, we need even fewer parameters

----------------------------------------------------------------------

Which parameters?

	It's very common to choose predictors based on preliminary analyses

	Or to throw out interaction or curvature terms based on significance

	This is accepting the null hypothesis (concluding these things don't matter)

	It's also introducing confirmation bias

		If we choose our final test based on the data, we will be bad frequentists

	Decide how many parameters you can afford based on the data

	Decide which parameters to use based on scientific judgment

		Can be based on other data, but not based on data from your study

SS Interactions

What is an interaction?

	So far, each predictor has its own effect, and the effects add up

		The effect of age on lung capacity is assumed to be the same for boys and girls

	An \textbf{interaction} means that the effect of one predictor depends on the value of another

		Does lung capacity increase faster with age for boys than for girls?

	Interactions are symmetric

----------------------------------------------------------------------

Interactions in R

	lm($y \sim x + z$)

		Additive model: no interaction

	lm($y \sim x * z$)

		Short for lm($y \sim x + z + x:z$)

		The new “lm variable” is made by multiplying $x$ and $z$

	Is this still a linear model?

	How many parameters does an interaction add?

	Example fev
