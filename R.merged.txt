SEC Working with R and rstudio

----------------------------------------------------------------------

R is a programming language

	Whether you are writing programs or not, you should understand
	roughly what that means

	A program is a collection of simple instructions (read, write, send,
	manipulate, calculate) to be executed in a logical order

	A program's flow is controlled by \emph{control structures}
	(instructions about what instruction to do next)

----------------------------------------------------------------------

What is rstudio?

	OLDANS An interface for working with R

	OLDANS Manage files, organize them into projects, develop and run
	scripts

		OLDANS Does not have to be complicated

		\emph{human work} in a project

		OLDANS Github is a site for managing and sharing git projects

	Should we try to get into git?

		STUDENTS Yes

----------------------------------------------------------------------

Principles and practice

	Your project should be

		Replicable

			Restart R and run everything again to test

			Don't do `rm' instead

				ANS Does not clear everything

		Shareable

			Use R projects and the `here' package

			Don't use absolute file paths like `C:myName/myDirectory'

		Traceable

			Use version control!

----------------------------------------------------------------------

R is old-fashioned

	Does not distinguish between values and vectors of values!

		Tries to figure out what you want

	Does not require print() most of the time

	Tries to figure out when a command is done instead of making you
	signal

----------------------------------------------------------------------

Scripting should be structured

	R and its ancestors were developed when people were using tiny
	terminals

		... or punch cards!

	Try to avoid these tricks and shortcuts; they can lead to trouble

	Be conscious of what belongs in your script (reproducible, key steps)

		and what you can just type in the console

Missing value logic

	R thinks about missing values in careful ways

		This can be confusing

	What is the mean of 6kg, 5kg and NA?

		ANS If you're being careful, it is NA. So that is the default

	5cm?

		ANS If footLength is NA you don't know whether it's $>$ 5cm

			ANS To be careful, R should report those mice to you

Finding outliers

Quality control

	Always keep original data-entry media

		Take notes in a lab book, or in the margin, or on the spreadsheet

	Double-check \emph{everything} you enter or transcribe

		If copy-pasting, triple-check

	Make notes of everything you change, and why

	If you find a mistake only because it's an outlier, that means your
	systems have failed

----------------------------------------------------------------------

Functions

	R comes with a \emph{lot} of useful functions

	Others can be loaded from “packages”

	You add new packages to your “library” with `install.packages()'

	And load them into your R session with `library()'

----------------------------------------------------------------------

Tidyverse

	tidyverse is a \emph{group} of packages designed to allow data
	manipulation and visualization at a higher conceptual level than
	base R

		works primarily on tables

		focuses on logical structure

		We will try to keep things simple by staying “tidy”

			This may still be a controversial choice

----------------------------------------------------------------------

Loading

	If you say `library(tidyverse)` it will load a bunch of packages

		But not all of the ones you installed with tidyverse

	This is fine!

	Some people prefer to just install what they're using

		For clarity

		Or because they are addicted to restarting R, like me
