Types of data

Numeric variables

	Interval and ratio variables are usually numeric

	These can be stored as continuous numbers or integers; it often
	won't matter to us

----------------------------------------------------------------------

Non-numeric variables

	Have two representations:

		The name itself is a character variable

		A pointer to a list of legal names is a factor variable

	R needs to convert characters to factors to analyze or plot

	We will try to help you navigate this without worry

dplyr verbs

	filter() chooses rows based on column values

	select() changes whether or not a column is included

	mutate() changes the values of columns and creates new columns

	summarise() collapses each group into a single row (by calculating something)

		count() collapses each group into a single row (by just counting rows)

	NOTES HREF https://dplyr.tidyverse.org/articles/dplyr.html Intro to dplyr

	CLASS See intro to dplyr
