SEC Approach and assumptions

What is a linear model?

	A \emph{fit} to a \textbf{response variable} based on assumptions about its relationship to one or more \textbf{predictor variables}

	\emph{Inferences} about parameters based on assumptions about the \emph{conditional} distribution of the response variable

		Assume the response variable has “true” distribution for any value of the predictor variables

			PREANS An example

			STUDENTS Use temperature to predict deaths	

	A linear model gives the response variable as a linear combination of the \emph{parameters} it is estimating

		OLDANS It is not necessarily linear with respect to predictor variables!

----------------------------------------------------------------------

Linear model?

$y$ is response, $x$ is predictor

	$y = a + b x$

	$y = a + b x + c x^2 + d x^3$

	$y = \frac{a}{b+x}$

	$y = a x^b$

	$\log(y) = \log a + b \log(x)$

	OLDANS 1, 2 and 5 are lms

		OLDANS Linear in a, b, ...

	OLDANS 4 and 5 are the same equation, but imply a different \emph{distribution} for $y$

	ADD Say “the response variable”

Linear model?

	What if $x$ is a categorical variable?

		OLDANS \emph{Any} response to a categorical variable can be encoded as a linear model!

Assumptions

	Linear-model \emph{fits} are basically always correct, but can be hard to interpret

		You can find the “best” parameters

		But you need assumptions to know what that means

	Linear-model \emph{inferences} (parameter estimates P-values, CIs) depend on assumptions about \emph{residuals}

	A residual is $y-\hat y$: the difference between an observed value $y$ and a model prediction $\hat y$

	lm inference assumes that residuals are independent and normally distributed, with constant variance

		The mean of the residuals is always 0

		OLDANS Otherwise the machine would find a better linear model

Variables

	What kind of variables can we use?

	Response

		OLDANS We assume the response variable is normally distributed (conditional on the predictor variables)

		OLDANS Therefore it must be continuous

		OLDANS The linear model framework gives us a lot of flexibility to construct a model

		OLDANS Predictor variables can be of any type

		OLDANS e.g., Continuous, integer, ordinal, nominal

Interpreting diagnostics

	Your linear model assumptions are not met exactly

		You can't use failure to reject the null hypothesis as evidence that your assumptions are OK

	There is no universally accepted way to decide whether you are close enough!

		When sample size gets larger, your ability to reject the null hypothesis get stronger

		But concerns often get smaller

			Particularly normality concerns

			OLDANS central limit theorem!

	We may circle back to this for projects

Effect sizes

	What are the units of our parameter in this example?

		ANS ml CO2/h for the mouse activity

			ANS Or: (ml CO2/h)/degC!

		ANS inches for the height …

	How should we know if they are large or not?

		ANS Compare to population statistics, not inferential statistics

		ANS We want to know if the value is large compared to something real, not compared to our own uncertainty!

		ANS e.g., total value, variation in population, difference between sexes, difference between species …

		ANS Use a log scale!

----------------------------------------------------------------------

Measures of size

	We can examine size of a parameter in two ways

	Certainty

		ANS t value, P value

		ANS This is usually our certainty about the sign of something -- but what?

	Effect

		ANS Unit-ed value, ratio of value to something with same units

		ANS or a log ratio

----------------------------------------------------------------------

Measures of spread

	Standard deviation

		ANS How much variation we see in the population

		ANS Compare this to understand the effect estimate

	Standard error (or confidence interval)

		ANS How much variation we would expect to see if estimated the parameter again

		ANS Compare this to understand the certainty of something

Parameterizing

	Different two-group models have the same fit

		ANS predicted mean for each observation

		ANS estimated standard deviation

	but different parameterizations

		baseline and difference (default for categorical variables)

		intercept and slope (default for continuous variables)

		mean and difference

	lm does not work with too many parameters

		ANS You would need to choose two in this case

		ANS Because we're interested in a mean for each group
