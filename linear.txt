What is a linear model?

	A \emph{fit} to a \textbf{response variable} based on assumptions about its relationship to one or more \textbf{predictor variables}

	\emph{Inferences} about parameters based on assumptions about the \emph{conditional} distribution of the response variable

		Assume the response variable has “true” distribution for any value of the predictor variables

			ANS An example

	A linear model gives the response variable as a linear combination of the \emph{parameters} it is estimating

		ANS It is not necessarily linear with respect to predictor variables!

----------------------------------------------------------------------

Linear model?

$y$ is response, $x$ is predictor

	$y = a + b x$

	$y = a + b x + c x^2 + d x^3$

	$y = \frac{a}{b+x}$

	$y = a x^b$

	$\log(y) = a + b \log(x)$

	ANS 1, 2 and 5 are lms

		ANS Linear in a, b, ...

	ANS 4 and 5 are the same equation, but imply a different \emph{distribution} for $y$

Assumptions

	Linear-model \emph{fits} are basically always correct, but can be hard to interpret

		You can find the “best” parameters

		But you need assumptions to know what that means

	Linear-model \emph{inferences} (parameter estimates P-values, CIs) depend on assumptions about \emph{residuals}

	A residual is $y-\hat y$: the difference between an observed value $y$ and a model prediction $\hat y$

	lm inference assumes that residuals are independent and normally distributed, with constant variance

		The mean of the residuals is always 0

		ANS Otherwise the machine would find a better linear model

Interpreting diagnostics

	Your linear model assumptions are not met exactly

		You can't use failure to reject the null hypothesis as evidence that your assumptions are OK

	There is no universally excepted way to decide whether you are close enough!

		When sample size gets larger, your ability to reject the null hypothesis get stronger

		But concerns often get smaller

			Particularly normality concerns

			ANS central limit theorem!

	We may circle back to this for projects

Effect sizes

		ANS ml CO2/h for the mouse activity

		ANS inches for the height …

Parameterizing

	Different two-group models have the same fit

		predicted mean for each individual

	but different parameterizations

		mean and difference

		baseline and difference

		intercept and slope

	lm does not work with too many parameters

		ANS You would need to choose two in this case

		ANS Because we're interested in a mean for each group
